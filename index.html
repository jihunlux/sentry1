SENSOR SYSTEM

센서 구성

기본 센서는 고정이며, 추가 모듈은 측정 대상과 호환성을 확인한 뒤 선택합니다.

℃기본 센서

온도 센서

보관 환경의 온도를 측정합니다. 허용 범위는 시약별 보관 지침을 확인해 설정해야 합니다.

↻기본 센서

용기 개폐 감지

용기가 열린 시점과 닫힌 시점을 기록합니다. 실제 기록에는 호환되는 감지 하드웨어가 필요합니다.

◌기본 센서

습도 센서

주변 상대습도를 측정합니다. 주변 습도와 시약 자체의 수분 함량은 서로 다른 값입니다.

☼선택형 모듈

광학 센서

빛 노출을 확인하는 용도입니다. 시약에 맞는 파장과 노출 기준을 별도로 검토해야 합니다.

⌁선택형 모듈

전기화학 센서

특정 물질이나 전기화학적 지표에 사용할 수 있습니다. 모든 시약에 범용으로 적용되지는 않습니다.

◉선택형 모듈

전용 가스 센서

특정 기체를 감지합니다. 대상 기체, 농도 범위, 간섭 물질에 맞는 센서를 골라야 합니다.

✳

FUTURE EXTENSION

식품 산패 측정으로 확장

식품 산패는 온도·습도만으로 확정할 수 없습니다. 산패 관련 지표를 직접 측정하는 검증된 센서 모듈과 비교 실험이 필요합니다.
